# GMK104 Image Custom Tool

`edited_zuoya_gmk104.layout` is the edited layout for the ZUOYA GMK104's screen. The vendor
tool that loads it (36 MB) isn't kept in the repo. Download `GMK104-Image-Custom-Tool.exe` from the
[gmk104-image-tool release](https://github.com/ricardoverginelli/levves/releases/tag/gmk104-image-tool)
and check it before running it:

```
sha256sum GMK104-Image-Custom-Tool.exe   # 0bd80015924a92f2319cc0962f865e4ddf4e5b1d8df45e0091e8706834d82fc2
```
